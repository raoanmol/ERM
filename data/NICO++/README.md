# Download Dataset
Since the dataset is huge. I'm not uploading it here. Here's how to set it up:
1. Go to the [Dropbox](https://www.dropbox.com/scl/fo/ix8u21atdwrstmgjkz2rx/AP5fheclFPjfbBMbeHoqPow?rlkey=kcbecly7tetqu57v4tsmo095m&e=2&dl=0)
2. Download the `DG_Benchmark` directory
3. Put it in `./data/NICO++/`
4. Unzip the `DG_Benchmark` directory within the `./data/NICO++/` directory
5. Ultimately your images will be in subdirectories in `./data/NICO++/DG_Benchmark/NICO_DG_Benchmark/` and your train/test distribution information will be in `./data/NICO++/DG_Benchmark/NICO_DG_Benchmark_annotation/` where `./` is your project root directory
